Desenvolvimento de Apps para Internet

A disciplina de Desenvolvimento de Aplicações para Internet aborda conceitos, técnicas e tecnologias para criação de aplicações web. Explora desenvolvimento front-end e back-end, linguagens como HTML, CSS, JavaScript e frameworks modernos, além de integração com bancos de dados, segurança, desempenho e boas práticas. O objetivo é capacitar os alunos a projetarem, implementar e manter aplicações web dinâmicas e responsivas.
